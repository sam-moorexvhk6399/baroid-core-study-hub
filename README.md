## Overview

Baroid Core Practice and Study Portal is an HTML-based learning application for people preparing for Baroid Core Exam material. Its study content brings together theory quizzes, business-process practice, product information, exam formulas, and drilling-fluids exercises in a responsive browser interface.

Alongside its review material, the portal offers interactive calculation and operational practice. Available activities include API 13B-1 alkalinity, barite mass balance, solids analysis, hole volume, and circulation. Exercises can generate varied inputs and provide guided steps, allowing users to repeat workflows while browser storage maintains local study data and progress between sessions.

## Frequently Asked Questions

### Who should use this portal?

The portal is designed for learners reviewing Baroid Core Exam subjects, business processes, drilling fluids, calculations, and related product knowledge.

### Are calculation exercises included?

Yes. The application includes practice tools for API 13B-1 alkalinity, barite mass balance, solids analysis, hole volume, and circulation.

### Are the exercise inputs always the same?

No. Several activities can use randomized parameters, making it possible to repeat the same type of workflow with different values.

### Where does the application keep my progress?

Progress and associated study data are stored in local browser storage for the current device and browser profile.

### Why might saved progress no longer appear?

Confirm that browser storage is enabled and that you are using the same browser profile. Private browsing, clearing site data, or changing browsers may remove the data or make it unavailable.

### How can I access newer versions?

Open the hosted [latest build](https://sam-moorexvhk6399.github.io/baroid-core-study-hub/) or review the repository for release and change information.

### How are portal settings managed?

Settings are kept locally in the browser rather than on a dedicated settings server. The browser's site-data controls can reset the stored information.
